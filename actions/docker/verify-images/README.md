## Overview

Verify existing keyless Cosign signatures on digest-qualified OCI images or Helm charts.
Configure registry authentication before calling this action, for example with
[Docker setup](../setup/README.md) in registry-only mode.
Specify exactly one certificate identity or regular expression, and the expected
OIDC issuer. Prefer an exact identity; anchor regular expressions to the trusted workflow.
Verification fails for unsigned images, mismatched identities/issuers and registry errors.
No images are signed or changed, and no OIDC write permission is needed.
This checks signatures only. Build provenance and application validation remain
separate policies; [Docker promote images](../../../.github/workflows/docker-promote-images.md)
applies those checks before publication.

## Inputs

| **Input**                         | **Description**                                                                                         | **Required** | **Default**                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------ | --------------------------------------------- |
| **`images`**                      | Digest-qualified references, as a JSON array or separated by commas, spaces or newlines.                | **true**     | -                                             |
|                                   | Each reference must include a registry and SHA-256 digest, with an optional tag:                        |              |                                               |
|                                   | `ghcr.io/owner/repository/image@sha256:...` or `ghcr.io/owner/repository/image:tag@sha256:...`.         |              |                                               |
|                                   | Tag-only references are rejected. Repeated digests in the same repository are verified once.            |              |                                               |
| **`certificate-identity`**        | Exact expected Fulcio certificate identity. Required unless certificate-identity-regexp is set.         | **false**    | -                                             |
| **`certificate-identity-regexp`** | Expected certificate identity as a Go regular expression. Mutually exclusive with certificate-identity. | **false**    | -                                             |
| **`certificate-oidc-issuer`**     | Exact expected OIDC issuer.                                                                             | **false**    | `https://token.actions.githubusercontent.com` |
